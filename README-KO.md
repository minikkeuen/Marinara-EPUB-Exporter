# Marinara EPUB Exporter v0.7.0

# Marinara EPUB Exporter v0.3.1

현재 Marinara 채팅 하나를 표준 EPUB 3 파일로 내보내는 Personal Extension입니다.

## v0.3.1
- 유저 입력과 캐릭터 지문을 동일한 본문 스타일로 출력
- 캐릭터명 / 페르소나명 표시를 각각 선택 가능
- 턴 구분 방식: 가로선(기본), 여백, 없음
- `[ ... ]`, `【 ... 】`, Status/상태 계열 상태창 제거 옵션
- 저장된 번역문이 있으면 번역문 우선, 없으면 원문 사용
- 시간 표시 및 system/기타 메시지 포함 옵션 유지

## 사용
1. Marinara의 Personal Extensions에서 ZIP을 가져옵니다.
2. 채팅 화면에서 `EP` 버튼을 누릅니다.
3. 원하는 옵션을 정하고 **현재 채팅 EPUB 내보내기**를 누릅니다.


## v0.3.1
- 작성자 이름 표시를 하나의 체크박스로 통합했습니다.
- 서버가 메시지 page size를 제한해도 이전 페이지를 계속 조회하여 첫 도입부 메시지가 누락되지 않도록 수정했습니다.


## v0.3.1
- 메시지 pagination이 서버 규격 `?limit=N&before=CURSOR`를 사용하도록 수정했습니다.
- 이전 대화와 최초 도입부까지 페이지를 거슬러 올라가 수집합니다.


## v0.3.1
- 메시지 API에서 `limit`를 생략해 Marinara의 `storage.listMessages()` 전체 히스토리 응답을 그대로 사용합니다. 도입부부터 최신 메시지까지 한 번에 가져옵니다.


- `캐릭터 도입부 포함` 옵션을 켜면 현재 캐릭터 카드의 `first_mes`를 EPUB 맨 앞에 보완 삽입합니다. 동일한 도입부가 실제 메시지에 이미 있으면 중복 삽입하지 않습니다. export 직전에 체크를 끄면 도입부를 제외할 수 있습니다.


## v0.3.1
- 상태창에서 날짜를 추출해 날짜가 바뀔 때만 전자책 본문에 날짜 마커를 표시합니다.
- `N일 차`, `N일차`, `DAY N`을 인식하면 `DAY N`을 함께 표시하고, 없으면 날짜만 표시합니다.
- 날짜 출력 형식은 `YYYY. MM. DD`입니다.
- `[ 31일 차 | 2025-04-25 / 오후 08:45 | ... ]` 같은 파이프형 상태창도 상태창 제거 대상으로 인식합니다.


## v0.3.1 수정
- 상태창만 있는 메시지에서도 날짜 마커가 사라지지 않도록 처리 순서를 수정했습니다.
- 번역문에 상태창이 없더라도 원문 상태창의 날짜를 읽어 날짜 마커를 생성합니다.


## v0.3.1
- Roleplay 화면의 우측 상단 툴바에서 Gallery 바로 앞에 EPUB 아이콘을 표시합니다.
- 기존 화면 우하단 플로팅 EPUB 버튼은 제거했습니다.
- 모바일에서는 별도 플로팅 버튼을 만들지 않습니다.
- 툴바가 다시 렌더링되어도 EPUB 버튼을 자동으로 복구합니다.


## v0.7.0

- 마지막 내보내기 설정을 기기에 기억합니다. 책 제목은 채팅별 값이므로 기억하지 않습니다.
- 파일명 규칙: 책 제목 / 캐릭터명 - 책 제목 / 책 제목 - 날짜
- 상태창 날짜를 기준으로 EPUB 챕터와 목차를 나눌 수 있습니다. 날짜를 찾지 못하면 기존처럼 한 챕터로 내보냅니다.


## v0.7.0

- 날짜별 챕터 분할 시 첫 날짜가 나오기 전의 메시지는 이후 날짜에 합치지 않고 `날짜 없음` 챕터로 분리합니다.


## v0.7.0

- 날짜별 챕터 분할을 켠 경우 본문 날짜 마커를 중복 표시하지 않고 챕터 제목에만 날짜를 표시합니다.


## v0.7.0

- 채팅을 전환하면 책 제목 입력칸을 새 채팅 제목으로 자동 갱신합니다.
- 같은 채팅에서 사용자가 직접 수정한 책 제목은 패널을 다시 열어도 유지합니다.


## v0.7.0

- 본문 앞뒤에 붙은 `[ ... ]` / `【 ... 】` 상태창도 상태 패널로 판정되면 제거합니다.
- 첫 날짜 이전 구간은 날짜별 챕터 분할 시 챕터명을 표시하지 않습니다.


## v0.7.0

- 상태창 제거 판정에서 날짜 의존성을 제거했습니다. 날짜가 없어도 `[ 항목 | 항목 | ... ]` 또는 `【 항목 | 항목 | ... 】`처럼 구분자로 구성된 상태창은 제거합니다.


## v0.7.0

- 본문 저장 방식을 선택할 수 있습니다.
  - 번역문 우선: 번역문이 있으면 번역문, 없으면 원문
  - 원문 우선: 원문이 있으면 원문, 없으면 번역문
- 선택값은 다른 내보내기 설정과 함께 기억됩니다.


## v0.7.0

- Roleplay의 기존 상단바 삽입 코드는 그대로 유지합니다.
- Roleplay 상단바가 없는 Conversation 모드에서만 Gallery + Search + Settings 툴바를 찾아 EPUB 버튼을 추가합니다.
